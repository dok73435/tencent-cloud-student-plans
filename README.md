## 配置怎么选：2核2G、2核4G 和 CVM 分别适合谁

2核2G 够跑博客和课程作业，2核4G 适合 Docker 和毕设系统，CVM 那档大多数学生用不上。

2核2G 搭配 4M 带宽，适合个人博客（WordPress、Halo）、课程作业、Linux 练习和轻量 API。同时开 MySQL、Nginx、PHP 会紧张，2G 内存很容易被吃满。省内存的办法有：用 SQLite 替代 MySQL，或者加一点 swap。

2核4G 搭配 5M 带宽，适合 Docker 多容器、毕设系统（前端 + 后端 + 数据库）、小型 Java 或 Node 服务。多出来的 2G 内存和 1M 带宽，在同时跑几个服务时差别很明显，这也是校园 2核4G 最值得加钱的地方。

CVM 2核4G 一年 789.36 元，适合课程明确要求 CVM、需要特定网络配置、或要和其他云产品对接的场景。纯学习用途，轻量的性价比高得多。

流量方面，300G 和 500G 对博客、课设、API 服务完全够用。打算做图床、视频站或文件下载的要注意，这类项目吃流量很快，额度用完会麻烦。

**超过 25 岁还能买腾讯云服务器学生版吗？**

**已经买过腾讯云服务器，还能买校园套餐吗？**
申请条件之一是"未购买过对应产品"。买过轻量应用服务器的账号，很可能不符合这一条，具体以活动页对你账号的判定为准。这种情况可以看同价续费或买赠套餐。

**2核2G 能装 Docker 吗？**
能装。但 2G 内存同时跑多个容器会吃紧，建议只跑一两个服务；打算长期用 Docker 的，直接选 2核4G。

**校园套餐到期后能按原价续费吗？**
活动页没有统一公布续费价，续费一般按官网价格。想锁定长期成本，优先考虑同价续费套餐。

**校园套餐和 38 元首单能同时买吗？**
两边的限购条件分开计算。按活动解读不冲突，可以先领校园套餐再下单首单秒杀，下单前确认账号资格。

**免费试用和校园套餐哪个先？**
想先验证性能和网络，先领 1 个月免费试用更稳。试用是首单性质，用掉后是否影响校园套餐资格，以活动页规则为准。
